# 🔥 FOOD CRAFT — Multi-Kitchen Food & Drinks Customization Studio

An interactive artisanal culinary studio built with **React + Vite**. Customers can select dish stations, customize exact gourmet ingredients with live animations, and place pickup orders with instant WhatsApp kitchen slips in **Indian Rupees (₹)**.

---

## 🚀 Quick Start

To run the project locally in development mode:

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Start the Vite development server
npm run dev
```

The app will start at `http://localhost:5173/` with lightning-fast Hot Module Replacement (HMR).

### Production Build

To build optimized production assets:

```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack & Features

- **Framework**: React 18
- **Bundler & Dev Server**: Vite 5
- **Brand**: **FOOD CRAFT**
- **Theme**: Dark Charcoal & Fiery Ember with Emerald Accents
- **Currency**: Indian Rupees (₹)
- **Features**:
  - **6 Dedicated Craft Studios**:
    1. 🌯 **Shawarma & Rolls**: Artisanal Flatbread, Toum Garlic Spread, Carved Chicken, Pickles, Sumac Onions & Butcher Roll.
    2. 🍔 **Smash Burgers**: Toasted Brioche, Secret Relish, Smashed Beef/Zinger/Paneer Patties, Melted Cheddar & Bun Crowning.
    3. 🍕 **Woodfired Pizzas**: Neapolitan Dough, San Marzano Marinara, Fresh Mozzarella Medallions, Cupped Pepperoni, Olives & Bubbly Bake.
    4. 🍗 **Charcoal Sizzlers**: Cast Iron Platter, Spiced Garlic Butter Basting, Tandoori Chicken Leg, Shish Tawook, Seekh Kebabs & Sizzle.
    5. 🍚 **Loaded Biryani Bowls**: Saffron Basmati Rice, Spiced Salan Gravy, Dum Meat, Katsu, Boiled Spiced Egg, Birista Onions & Cooling Raita.
    6. 🥤 **Drinks, Shakes & Boba**: Chilled Highball Glass, Ice Cubes, Chocolate Fudge / Mango Syrup, Tapioca Boba Pearls, Vanilla Ice Cream Scoop, Whipped Cream & Shaking.
  - **Menu Section**: 27 artisanal dishes with direct Add / Quantity steppers and **"Custom 🛠️"** deep-linking to live craft stations.
  - **Live Digital POS Ticket**: Real-time itemized order slip with removal, quantity tracking, and live subtotal.
  - **WhatsApp Instant Order Slip**: Pre-formatted kitchen pickup ticket with customer name, phone, pickup time, and special instructions.
